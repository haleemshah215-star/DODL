# Turbo Drift

A simple browser-based 3D car racing game.

## Run locally

Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit: http://localhost:8000

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Open Vercel.
3. Click "Add Project" and import the GitHub repository.
4. Keep the default settings for a static project.
5. Deploy.

Every push to the selected branch will auto-deploy on Vercel.
